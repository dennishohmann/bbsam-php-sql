Datensätze löschen

Das Problem

Die Mitarbeiter-Tabelle des Katzencafe ist inzwischen ziemlich voll. Manche Katzen haben gekündigt, andere wurden wegen übermäßigem Kaffeekonsum entlassen.

Der Chef möchte einzelne Datensätze mit einem Klick aus der Tabelle entfernen können, ohne jedes Mal in phpMyAdmin gehen zu müssen.

Die Lösung: Jede Tabellenzeile bekommt einen "Löschen"-Link. Ein Klick darauf entfernt den Datensatz aus der Datenbank!

Das Konzept

Der Lösch-Vorgang funktioniert in 3 Schritten:

  1. Link mit ID: Jeder Lösch-Link enthält die ID des Datensatzes als GET-Parameter
    delete_1.php?delete=3
  2. Parameter empfangen: Die PHP-Seite prüft, ob ein delete-Parameter übergeben wurde
  3. Datensatz löschen: Mit DELETE FROM katzen WHERE id = ... wird der Eintrag entfernt

Datensätze wiederherstellen (hier klicken)

Falls du alle Katzen gelöscht hast:

  1. Öffne phpMyAdmin in deinem Browser (meistens unter localhost/phpmyadmin)
  2. Wähle die Datenbank "katzencafe" aus
  3. Klicke oben auf den Reiter "SQL"
  4. Kopiere den folgenden Code und füge ihn ein
  5. Klicke auf "OK" oder "Ausführen"
SQL-Code zum Wiederherstellen:
-- Datenbank erstellen
CREATE DATABASE IF NOT EXISTS katzencafe;
USE katzencafe;

-- Alle Katzen löschen und neu einfügen
DELETE FROM katzen;
ALTER TABLE katzen AUTO_INCREMENT = 1;

INSERT INTO katzen (name, spezialitaet, taeglicher_unfug, kaffee_konsum) VALUES

('Gräfin Flauschine', 'Gäste ignorieren', 'Wirft Zuckerstreuer vom Tisch', 0),
('Professor Maunz', 'Tastatur besetzen', 'Tippt Bestellungen um', 7),
('Sir Pfötchen III', 'Milch stehlen', 'Leckt heimlich die Sahne', 1),
('DJ Katzenklo', 'Um 3 Uhr nachts singen', 'Rennt grundlos durch den Raum', 12),
('Ninja Fellknäuel', 'Unsichtbar sein', 'Niemand weiß wo er ist', NULL),

Hinweis: Der Befehl ALTER TABLE katzen AUTO_INCREMENT = 1 setzt den ID-Zähler zurück, sodass die neuen Katzen wieder bei ID 1 beginnen.
