Voraussetzungen für MySQLi zu Hause

Um mit PHP und MySQLi auf deinem eigenen Computer arbeiten zu können, benötigst du folgende Software. Diese Anleitung zeigt dir, wie du alles einrichtest.

XAMPP installieren

Lokaler Webserver mit Apache, MySQL und PHP

Was ist XAMPP?

XAMPP ist ein kostenloses Softwarepaket, das einen Webserver (Apache), eine Datenbank (MySQL/MariaDB) und PHP auf deinem Computer installiert. Der Name steht für:

  • X - Cross-Platform (Windows, Linux, macOS)
  • A - Apache (Webserver)
  • M - MariaDB/MySQL (Datenbank)
  • P - PHP (Programmiersprache)
  • P - Perl (Programmiersprache)
Installation
Schritt 1: Gehe auf https://www.apachefriends.org und lade XAMPP für dein Betriebssystem herunter.
Schritt 2: Führe die heruntergeladene Datei aus und folge dem Installationsassistenten. Wähle mindestens Apache, MySQL und PHP aus.
Schritt 3: Installiere XAMPP am besten im Standardverzeichnis:
  • Windows: C:\xampp
  • macOS: /Applications/XAMPP
XAMPP starten
Schritt 1: Öffne das XAMPP Control Panel.
Schritt 2: Klicke auf "Start" bei Apache und MySQL.
Schritt 3: Wenn beide Module grün hinterlegt sind, läuft der Server.
Hinweis: Falls Apache nicht startet, könnte Port 80 bereits von einem anderen Programm (z.B. Skype) belegt sein. Beende das andere Programm oder ändere den Port in der Apache-Konfiguration.
Projektordner erstellen

Deine PHP-Dateien müssen im htdocs-Ordner gespeichert werden:

  • Windows: C:\xampp\htdocs
  • macOS: /Applications/XAMPP/htdocs
Tipp: Erstelle für jedes Projekt einen eigenen Unterordner in htdocs, z.B. C:\xampp\htdocs\mysqli-projekt

phpMyAdmin

Webbasierte Verwaltung für MySQL-Datenbanken

Was ist phpMyAdmin?

phpMyAdmin ist ein kostenloses Webtool zur Verwaltung von MySQL-Datenbanken. Es ist bereits in XAMPP enthalten und ermöglicht dir:

  • Datenbanken erstellen und löschen
  • Tabellen anlegen und bearbeiten
  • Daten einfügen, ändern und löschen
  • SQL-Befehle direkt ausführen
  • Datenbanken importieren und exportieren
phpMyAdmin öffnen
Schritt 1: Stelle sicher, dass Apache und MySQL in XAMPP gestartet sind.
Schritt 2: Öffne deinen Browser und gehe zu: http://localhost/phpmyadmin
Schritt 3: Du bist jetzt in phpMyAdmin eingeloggt (standardmäßig als Benutzer "root" ohne Passwort).
Erste Datenbank erstellen
Schritt 1: Klicke links auf "Neu" oder oben auf den Reiter "Datenbanken".
Schritt 2: Gib einen Namen für deine Datenbank ein (z.B. schule).
Schritt 3: Wähle als Kollation utf8mb4_general_ci für deutsche Umlaute.
Schritt 4: Klicke auf "Erstellen".
Sicherheitshinweis: Der Standardbenutzer "root" hat kein Passwort. Für lokale Entwicklung ist das in Ordnung, aber setze niemals einen Server ohne Passwort im Internet ein!

Visual Studio Code

Kostenloser Code-Editor von Microsoft

Was ist Visual Studio Code?

Visual Studio Code (VS Code) ist ein kostenloser, leistungsstarker Code-Editor. Er bietet:

  • Syntax-Highlighting für PHP, SQL, HTML, CSS und viele weitere Sprachen
  • Automatische Code-Vervollständigung
  • Integriertes Terminal
  • Erweiterungen für zusätzliche Funktionen
  • Git-Integration
Installation
Schritt 1: Gehe auf https://code.visualstudio.com
Schritt 2: Lade VS Code für dein Betriebssystem herunter.
Schritt 3: Installiere das Programm mit den Standardeinstellungen.
Empfohlene Erweiterungen für PHP

Öffne VS Code und installiere folgende Erweiterungen (Strg+Shift+X oder Cmd+Shift+X):

  • PHP Intelephense - Intelligente Code-Vervollständigung für PHP
  • German Language Pack - Deutsche Benutzeroberfläche
Projekt öffnen
Schritt 1: Öffne VS Code.
Schritt 2: Gehe zu Datei → Ordner öffnen
Schritt 3: Navigiere zu deinem Projektordner in htdocs und öffne ihn.
Tipp: Erstelle eine neue Datei mit Strg+N (Windows) oder Cmd+N (macOS) und speichere sie mit der Endung .php

Checkliste: Alles bereit?

  • XAMPP ist installiert
  • Apache startet ohne Fehler (grün im Control Panel)
  • Die Dateien im Projektordner sind erreichbar über http://localhost
  • MySQL startet ohne Fehler (grün im Control Panel)
  • phpMyAdmin ist erreichbar unter http://localhost/phpmyadmin
  • VS Code ist installiert
  • PHP-Erweiterungen in VS Code sind installiert

Erster Test: PHP funktioniert?

Erstelle eine Datei namens test.php in deinem Projektordner mit folgendem Inhalt:

<?php
echo "Hallo Welt!";
?>

Öffne dann im Browser: http://localhost/dein-projektordner/test.php

Wenn du "Hallo Welt!" siehst, funktioniert alles!
