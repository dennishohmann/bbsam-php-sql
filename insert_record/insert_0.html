Neue Katzen einstellen

Das Katzencafe boomt!

Das Katzencafe ist so erfolgreich, dass dringend neue Mitarbeiter gebraucht werden! Jeden Tag kommen Bewerbungen von talentierten Katzen aus der ganzen Stadt.

Der Chef hat keine Lust mehr, neue Mitarbeiter umständlich über phpMyAdmin einzutragen. Er wünscht sich ein einfaches Formular, mit dem er neue Katzen direkt einstellen kann.

Die Lösung: Ein HTML-Formular, das die Daten an PHP schickt, welches sie dann sicher in die Datenbank einfügt!

GET vs POST - Wann benutze ich was?
GET POST
Daten sichtbar? Ja, in der URL
?name=Minka&job=Service		 Nein, unsichtbar im Hintergrund
Datenmenge Begrenzt (~2000 Zeichen) Praktisch unbegrenzt
Typische Verwendung Links, Suchen, Filter, Sortierung Formulare, Passwörter, neue Daten
Beispiel Lösch-Links (delete_record) Anmeldeformulare, Einträge erstellen
Merksatz: GET für Abrufen (Daten holen), POST für Absenden (Daten senden).

Datenbank vorbereiten (hier klicken)

Bevor du anfängst: Die Katzen-Tabelle muss um drei Spalten erweitert werden.

  1. Öffne phpMyAdmin in deinem Browser (meistens unter localhost/phpmyadmin)
  2. Wähle die Datenbank "katzencafe" aus
  3. Klicke oben auf den Reiter "SQL"
  4. Kopiere den folgenden Code und füge ihn ein
  5. Klicke auf "OK" oder "Ausführen"
SQL-Code - Tabelle erweitern:
-- Drei neue Spalten hinzufügen
ALTER TABLE katzen
ADD COLUMN eingestellt_am DATE DEFAULT NULL AFTER kaffee_konsum,
ADD COLUMN gehalt DECIMAL(8,2) DEFAULT 0.00 AFTER eingestellt_am,
ADD COLUMN abteilung ENUM('Küche', 'Service', 'Unterhaltung', 'Sicherheit', 'Management') DEFAULT 'Service' AFTER gehalt;

-- Bestehende Katzen mit zufälligen Werten füllen
UPDATE katzen SET
    eingestellt_am = DATE_SUB(CURDATE(), INTERVAL FLOOR(RAND() * 365) DAY),
    gehalt = ROUND(1500 + RAND() * 1500, 2),
    abteilung = ELT(FLOOR(1 + RAND() * 5), 'Küche', 'Service', 'Unterhaltung', 'Sicherheit', 'Management');
Was passiert hier?
ALTER TABLE fügt neue Spalten zur bestehenden Tabelle hinzu.
UPDATE füllt die bestehenden Katzen mit zufälligen Werten.
ENUM erlaubt nur bestimmte Werte (wie ein Dropdown).
Katzen wiederherstellen (falls alle gelöscht)

Falls du alle Katzen gelöscht hast:

SQL-Code zum Wiederherstellen:
-- Datenbank erstellen
CREATE DATABASE IF NOT EXISTS katzencafe;
USE katzencafe;

-- Tabelle neu erstellen (mit allen Spalten)
DROP TABLE IF EXISTS katzen;
CREATE TABLE katzen (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),
    spezialitaet VARCHAR(200),
    taeglicher_unfug VARCHAR(200),
    kaffee_konsum INT,
    eingestellt_am DATE DEFAULT NULL,
    gehalt DECIMAL(8,2) DEFAULT 0.00,
    abteilung ENUM('Küche', 'Service', 'Unterhaltung', 'Sicherheit', 'Management') DEFAULT 'Service'
);
