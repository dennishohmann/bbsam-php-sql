Willkommen im Katzencafe!

Das Problem

Das Katzencafe hat ein ernstes Problem: Die Katzen-Mitarbeiter sind vollkommen chaotisch!

Herr Schnurrbert behauptet, er sei der Barista - dabei verschläft er jeden Tag im Brotkorb. DJ Katzenklo trinkt 12 Tassen Kaffee pro Tag und singt um 3 Uhr nachts. Und Ninja Fellknäuel? Den hat seit Wochen niemand gesehen.

Niemand weiß mehr, wer welche Spezialität hat, wer wieviel Kaffee trinkt, und wer für welchen täglichen Unfug verantwortlich ist.

Die Lösung: Eine Datenbank zur Mitarbeiterverwaltung! Mit PHP und MariaDB bringen wir endlich Ordnung ins Chaos.

Datenbank einrichten (hier klicken)

So richtest du die Datenbank ein:

  1. Öffne phpMyAdmin in deinem Browser (meistens unter localhost/phpmyadmin)
  2. Klicke oben auf den Reiter "SQL"
  3. Kopiere den folgenden Code und füge ihn ein
  4. Klicke auf "OK" oder "Ausführen"
SQL-Code zum Kopieren:
-- Datenbank erstellen
CREATE DATABASE IF NOT EXISTS katzencafe;
USE katzencafe;

-- Tabelle für die Café-Katzen
CREATE TABLE katzen (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50),
    spezialitaet VARCHAR(100),
    taeglicher_unfug VARCHAR(200),
    kaffee_konsum INT
);
